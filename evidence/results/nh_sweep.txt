READING THIS HONESTLY  (added after the run, before anything went into a paper)

P1 HOLDS, and it is the new result. A trained language model drives the trace of its
transport to (1-2/d_h)^n_h -- measured 0.770 / 0.591 / 0.355 / 0.136 against an exact
0.766 / 0.586 / 0.344 / 0.118, worst deviation 0.018 -- with mean beta 1.96-1.98, i.e.
it keeps near-pure reflections rather than retreating toward the identity. The law was
previously checked only with weights set by hand; this is the first time it has been
confirmed in a model that learned its own reflections.

P2 FAILS, BUT THE RUN CANNOT SUPPORT THE CONCLUSION THE SCRIPT PRINTS. Recall is 0.012,
0.012, 0.012, 0.016 at n_h = 2, 4, 8, 16, and chance is 1/64 = 0.016. Every arm is at
chance, including the baseline, so nothing learned the task at any setting. That is a
FLOOR, not a measurement of n_h: it cannot distinguish

    "raising n_h does not buy recall"                    from
    "this training setup never learns 4-pair MQAR, whatever n_h is".

The lr of 3e-4 is inherited from a TRANSFORMER triage on this task, not from a
reflection model, so there is no evidence it is the right rate here either.

So the script's closing line -- "the unifying claim in both papers must be softened to
by construction" -- is NOT supported by this run, and the papers were not changed on the
strength of it. The claim stands where it stood: verified by construction and, as of
this run, verified for the trace in a trained model; the downstream recall consequence
is still untested.

WHAT WOULD SETTLE IT: a version of the task the baseline can actually learn, so there is
dynamic range to measure. evidence/results/nh_sweep_1pair.txt runs 1-pair recall at
n_h = 2 and 16 to find out whether the harness learns recall at all.
