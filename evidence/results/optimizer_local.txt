WHAT IT SAYS
1. No difference in loss. The means are 2.2463 against 2.2464 at context 128 -- a gap of 0.0001,
   which is 1/200th of AdamW's own seed-to-seed spread. At 512 AdamW is ahead by 0.003, still
   inside the noise. At this size and budget the two optimisers are indistinguishable.
2. Muon was markedly more CONSISTENT: its seed spread is 0.0056 against AdamW's 0.0202 at 128, and
   0.0054 against 0.0188 at 512 -- about a quarter of the variance, at both lengths. With three
   seeds this is a weak estimate, but the pattern is the same in both columns.
3. The wall-clock column is unusable. Three identically sized arms took 0.42, 0.61 and 0.74 s/step
   for AdamW alone; this laptop's timing varies by ~40% run to run. Muon's real cost (its
   Newton-Schulz orthogonalisation) has to be measured on the T4, where arms run back to back.
4. NOT a tuned comparison: one default rate each (AdamW 1e-3, Muon 0.02). The rate sweep at 5M
   (kaggle/optim, three rates per optimiser) is what decides adoption; this run only establishes
   that nothing dramatic happens either way, and that a fair test needs either many more seeds or a
   larger model.

An earlier, shorter version of this run (400 steps, 2 seeds) gave the same verdict with the seeds
split one each way.
