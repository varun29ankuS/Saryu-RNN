WHAT IS MISSING -- diagnosed, not guessed

RESULT: carve+bind 0.184 / 0.066 / 0.020 against base 0.113 / 0.020 / 0.012. P1 missed
(+0.070, needed +0.09), P2 failed outright, P3 held. Carving moved gap 16 by 5x
(0.020 -> 0.098) and binding moved gap 4 by 63% (0.113 -> 0.184). Real, but nowhere near
the 0.97 the same mechanism reaches by construction. Three deficits explain the distance,
and two of them are mine.

1. THE BINDER IS k=1 IN AN 8-DIMENSIONAL SUBSPACE, SO THE CEILING IS 0.430.
   By construction, carved, 4 pairs, memory dimension 8 (evidence/memory_mechanisms.py,
   D=16 so the memory half is 8):

       k        1        2        4        8
       gap 0    0.430    0.590    0.687    0.737
       gap 16   0.417    0.537    0.683    0.717

   The trained arm reached 0.184 against a CEILING of 0.430. The architecture as built
   caps itself before training starts, because carve=8 leaves exactly one reflection for
   binding, and the trace law says one reflection in d=8 has overlap (1-2/8)^1 = 0.75 --
   almost no hiding at all. This is the same mistake the paper made at the layer level,
   repeated inside the memory subspace.

2. TRAINING REACHES 43% OF ITS OWN CEILING (0.184 of 0.430).
   A separate, genuine learnability gap: the model must learn to emit the SAME memory
   direction for a key at write time and at query time, from two different contexts. That
   is the content-addressing that attention gets for free from an explicit query-key dot
   product, and it has to be discovered here.

3. GAP 64 IS UNFIXED (0.020) BECAUSE CARVING PROTECTS AGAINST THE TRANSPORT BUT NOT
   AGAINST THE GATE. The write is h_M <- (1-g) h_M + g c with ONE SCALAR GATE PER HEAD, so
   the memory dimensions decay on the tracking head's timescale, retention ~25 tokens at
   g ~ 0.04. That is exactly the observed signature: gap 16 (< 25) partly survives, gap 64
   (>> 25) is washed out. Splitting inside a head forced tracking and memory to share the
   one resource they must not share.

THE FIX FOLLOWS FROM 1 AND 3, AND IT IS ALREADY SUPPORTED BY THE ARCHITECTURE.
Dedicate whole HEADS to memory instead of splitting dimensions inside a head:

   transport   identity, so nothing ever scrambles the memory head
   binding     ALL n_h reflections go to binding, in the full d_h = 16, not 1 in 8.
               At k=8, (1-2/16)^8 = 0.344 overlap; by construction that is 0.737, which is
               4x the ceiling of what was just tested.
   gate        its own, because gates are ALREADY per head -- long retention on the memory
               head, fast on the tracking heads, and NO kernel change is needed.

The per-head gate is the part that matters: a per-dimension gate would break the exact
kernel, which is why the state was never split this way before. Splitting by head avoids
that entirely, and the timescale ladder (gate_timescales) already exists to initialise a
long-retention head.
