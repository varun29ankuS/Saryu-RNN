One fact is learned perfectly at every rate. Four facts never leave chance at any rate: the loss sits

1. The curriculum is worth about 9x at identical width (0.273 against 0.031), so the cliff IS partly
   an optimisation barrier, as Boesch & Wee 2026 (2609.16183) report for fixed-state recurrences.
2. It stops at 0.23-0.37, which is at or just below the hand-built reflect-to-bind ceiling for these
   widths (0.42-0.46, recall_by_construction.txt). Training now reaches the mechanism's limit instead
   of failing to start.
3. Width does nothing: 0.336 / 0.367 / 0.273 across head dims 8 / 16 / 32. A real associative memory
   improves with width. This one cannot, because the binding overlap is 1 - 2/d, which gets WORSE as
   d grows (trace_law.txt).
4. Recall decays sharply with gap (0.234 -> 0.062) on top of the capacity ceiling, which the
   construction does not model: the transport rotates the stored superposition between write and
   read. Frame drift is a second, separate geometric cost.

CONCLUSION: two walls, not one. The optimisation wall yields to a curriculum. The capacity wall is
set by the trace of the binding operator and yields only to more reflections per token.
