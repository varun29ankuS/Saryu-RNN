  reflect-equiv holds, the failure is the missing inverse, not the store.

  transported too.

WHAT THIS SETTLES

THE TWO FAILURES ARE INDEPENDENT, AND EACH HAS A DIFFERENT FIX.

  capacity      set by k, reflections per bind, exactly as the trace law says. At 4 pairs,
                gap 0: k=2 gives 0.375, k=32 gives 0.995. At 8 pairs: 0.190 -> 0.885.
                The law's capacity claim is correct and is NOT what failed in the model.

  persistence   set by whether the READ is transported. Without that, every mechanism here
                decays to chance as the gap grows -- including the matrix memory:

                  4 pairs, k=32, gap 0 -> 64
                  reflect-naive   0.995 -> 0.235   (chance 0.250)
                  outer-naive     1.000 -> 0.315
                  reflect-equiv   0.995 -> 0.995
                  outer-equiv     1.000 -> 1.000

THE HEADLINE. "Bolt on a matrix memory" does not work by itself. outer-naive collapses to
chance just like the reflection store (1.000 -> 0.130 at 8 pairs). Conjugation is only
benign when the query is transported too. The universal requirement is the EQUIVARIANT
READ, not the choice of store.

BUT reflect-equiv and outer-equiv both need A, the accumulated transport, which a vector
state does not have. They are oracles here: upper bounds, not designs.

CARVING IS THE ONE FIX THAT NEEDS NO ORACLE. Confining the transports to a tracking
subspace leaves the memory subspace fixed, so the unbind commutes with the transport by
disjoint support -- no A required, no new state:

  k=32, carved:  4 pairs  0.970 0.960 0.980 0.975   across gaps 0, 4, 16, 64
                 8 pairs  0.715 0.720 0.705 0.700

Flat in gap, which is the property nothing else achieves without an oracle. It pays for it
in capacity, since the memory lives in half the dimensions.

ORDER OF WORK IMPLIED
  1. carve a memory subspace in the real model (one line in SaryuV3Block.forward)
  2. raise k for the carved heads only -- capacity is the second axis, and it is cheap once
     the memory is no longer scrambled
  3. a bivector/outer store only if 1+2 falls short; it is strictly better here (1.000
     everywhere) but needs d^2 state AND still needs the equivariant read

WHAT WOULD FALSIFY THE PLAN: if carving in the trained model leaves 4-pair recall at gap 4
within noise of the current 0.113, then scrambling is not the binding constraint and the
write rule is.
